COMPLETE FIX FOR FORGOT PASSWORD - TELEGRAM ID LINKING

The issue: Users who registered WITHOUT a Telegram ID cannot reset their password.

Solution: Allow them to provide/link their Telegram ID during the forgot password flow.

=== FRONTEND CHANGES ===

File: frontend/src/App.jsx

1. Update the forgot password step 1 form (around line 2456):

Replace the form with:
- Phone number field (required)
- Telegram ID field (OPTIONAL - but needed if not linked)
- Info box explaining:
  * If you already have Telegram linked, just enter phone
  * If not, enter both phone + Telegram ID
  * How to get Telegram ID from @userinfobot
- Link to @userinfobot

2. Update handleForgotPasswordRequest function:
- Remove the telegram ID validation (make it optional)
- Send both phoneNumber and telegramId (if provided) to backend

=== BACKEND CHANGES ===

File: backend/server.js

Update /api/v1/auth/forgot-password route logic:
1. Accept both phoneNumber and optional telegramId from request
2. Look up user by phone number
3. If user has NO telegram_id AND telegramId was provided:
   - Validate it's not already in use
   - Link it to the account (UPDATE users SET telegram_id)
4. If user has NO telegram_id AND none provided:
   - Return error asking them to provide it
5. Send code to their linked (or just-linked) Telegram ID

This allows:
- Users WITH Telegram linked: enter phone only → get code
- Users WITHOUT Telegram: enter phone + Telegram ID → link it → get code
