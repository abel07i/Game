# How to Get Your Telegram ID

To enable password recovery via Telegram, you need to provide your Telegram ID during registration.

## Steps to Get Your Telegram ID:

### Method 1: Using @userinfobot (Recommended)
1. Open Telegram app
2. Search for `@userinfobot`
3. Start a chat with the bot
4. The bot will automatically reply with your user information
5. Your **Telegram ID** will be shown (example: `123456789`)
6. Copy this number and paste it in the registration form

### Method 2: Using @getidsbot
1. Open Telegram app
2. Search for `@getidsbot`
3. Send any message to the bot
4. The bot will reply with your ID
5. Copy the number shown

### Method 3: Using Web Telegram
1. Open https://web.telegram.org
2. Log in to your account
3. The URL will show your ID: `https://web.telegram.org/a/#123456789`
4. The number after `#` is your Telegram ID

## Why is Telegram ID Needed?

- **Password Recovery**: If you forget your password, we'll send a verification code to your Telegram account
- **Security**: Ensures only you can reset your password
- **Convenience**: No need to remember security questions or wait for email

## Is it Required?

**No, it's optional** - but highly recommended!

- ✅ **With Telegram ID**: You can reset your password if you forget it
- ❌ **Without Telegram ID**: You'll need to contact support to reset your password

## Privacy & Security

- Your Telegram ID is stored securely in our database
- We only use it to send password reset codes
- We never share your Telegram ID with third parties
- The verification codes expire after 10 minutes

## Need Help?

If you have trouble getting your Telegram ID:
1. Make sure you have a Telegram account
2. Try using @userinfobot - it's the most reliable method
3. Contact support if you still need assistance
